# Introduction

Like the Community Edition, Ayakaleaf Pro comes as a Docker container and is a direct drop in replacement and additionally includes features such as SSO provided via LDAP and SAML2, improved security, tracked changes, comments, our optimized version of TeX Live, templates and administration panel.

Once you've depolyed the Community Edition using the Toolkit and familiarized yourself with the application, you can easily switch to Ayakaleaf Pro by following the instructions [here](using-the-toolkit/4.-get-overleaf-pro-images.md#switching-to-pro).
